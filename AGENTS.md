# AGENTS.md

Repo-local conventions for agents working in SovereignBench. The study design, research questions and scoring live in `pd-experiment/METHODOLOGY.md`; read that before changing anything under `pd-experiment/`.

## What this repo is

A published research artifact. The numbers in `README.md`, `pd-experiment/README.md` and `pd-experiment/analysis/FINDINGS_summary.md` are claims about named third-party models. If you change the data or the classification logic, those numbers move, and every doc that quotes them has to move with it. Recompute rather than copying a figure forward.

## Task YAML is stimulus, not config

`tasks/gen3-identity/` and `tasks/gen3b-language/` are generated by `pd-experiment/generators/`. Edit the generator and re-emit; a hand-edit to a generated file is lost on the next run.

The `instruction` text in a task is the exact string delivered to the model. Whitespace, keyword casing and naming order are experimental variables, not formatting. The two phrasings of each scenario differ only in which nation is named first, and that is the entire point of the order-balancing — do not "tidy" one of them.

This is why the repo is not formatter-managed. `ruff format` rewrites quoting inside the generator templates, which changes the emitted stimulus.

## Analysis

`analysis/build_dataset.py` loads the classifier out of `analysis/analyze.py` by path. Renaming or moving `analyze.py` breaks it silently.

`analysis/report.py` filters to `lang == "zh"` throughout. That scoping is left over from when English was a single pilot cell and the data has outgrown it, so its tables cover 96 of 289 rows. Do not present its output as the whole study. `FINDINGS_summary.md` is the cross-language readout.

`analysis/REPORT.md` and `analysis/figures/` are generated and gitignored. Don't commit them.

## Validation gate

The judge codings are pre-validation. No Cohen's κ has been computed, and `analysis/VALIDATION_adopt_reject.md` is an unfilled worksheet. Any statement of a coded result needs the pre-validation caveat attached until that gate is passed. Don't quietly drop it.

## Checks

```bash
uv sync
ruff check .            # the gate CI runs; rules live in pyproject.toml
pre-commit run --all    # YAML, large files, gitleaks
shellcheck pd-experiment/run.sh pd-experiment/run_en_balance.sh
```

## MUST

- Recompute a number rather than carrying it between documents
- Keep the pre-validation caveat on any coded result
- Re-emit generated task YAML through the generator
- Run `ruff check .` and `pre-commit run --all` before declaring work complete

## NEVER

- Reformat the generators or the task YAML
- Publish an internal identifier: workspace or project names, platform record UUIDs beyond the join keys already in the data, or another user's handle
- Commit `analysis/REPORT.md`, `analysis/figures/` or the transcript cache
- Bypass hooks with `--no-verify`
