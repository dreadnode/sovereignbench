# Security Policy

## Reporting a Vulnerability

Please contact Dreadnode support at [support@dreadnode.io](mailto:support@dreadnode.io).

Do not open a public issue for a security finding.

## Scope

This repository holds research tasks, a judge rubric and analysis scripts. It
runs no service and handles no credentials. The reports most useful to us are
prompt-injection or data-exfiltration paths in the judge rubric or the skill,
and anything in the published data that should not have been published.
